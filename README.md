# PRODIGY_DS_02

## Task 02: Data Cleaning and Exploratory Data Analysis (EDA)

This project focuses on performing data cleaning and exploratory data analysis (EDA) on the Titanic dataset to identify patterns and relationships between variables.

## Dataset Used
Titanic Dataset

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Performed

- Loaded dataset
- Handled missing values
- Removed duplicates
- Performed data analysis
- Created visualizations
- Identified patterns and trends

## Key Insights

- Females had higher survival rates than males
- First-class passengers had higher survival chances
- Fare influenced survival probability
- Age distribution showed varied survival trends
